# Halimah Alossaimi — Interactive Design Portfolio

A static three-page portfolio created for the Midterm Project: Portfolio Website & Interactive Art.

## Pages

- `index.html` — interactive homepage and project links
- `album-cover.html` — “On My Way” album cover and process
- `dog-park.html` — Future Indoor Dog Park concept and process

## Run locally

Open `index.html` directly, or serve this folder with any static web server.

## Publish with GitHub Pages

Upload the folder contents to a public GitHub repository. In the repository settings, open **Pages**, choose **Deploy from a branch**, then select the `main` branch and `/ (root)` folder.
